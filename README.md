# PhotoSort
## Photo Organizer

A simple tool I built to automatically organize a large collection of photos and videos by date.

I had around **1 TB of old photos** sitting on a drive, and manually organizing everything would have taken an unreasonable amount of time. So I decided to automate it.

The tool sorts media into a folder structure based on the date found in the file metadata:

`Year / Month / Day`

This is my **first vibe-coded project**, built primarily to solve a personal problem. I'm still learning programming, so the implementation may not be the most elegant or optimized.

Feel free to **use, fork, modify, or improve the project**. If you find bugs or have ideas for improvements, contributions are welcome.
